# 外屏助手 · External Display Helper

<img src="docs/icon.png" width="72" alt="外屏助手图标">

将手机直连显示器，在外屏全屏打开一个 Android 应用，同时把手机当作触控板。日常使用无需电脑、无线 ADB 或投屏服务器。**同一个 APK 既是手机上的助手，也是系统框架模块。**

**[下载 APK 与 SHA-256 校验文件](https://github.com/lwm38741/ExternalDisplayHelper/releases)** · [从旧版升级](#从双应用旧版升级) · [从源码构建](docs/BUILD.md)

## 适配范围

本项目基于**小米 17、HyperOS、Android API 37** 开发。此前双 APK 版的启动、应用切换、键鼠、触控板和内屏黑屏已在小米 17 上人工验证。1.1.0 将两部分合为一个安装包；已经构建并检查签名、组件及逻辑，**合并后的安装、重启与实际外屏会话尚待真机回归**。

其他机型、ROM、系统更新及显示设备请自行测试。即使同为 API 37，厂商系统内部接口也可能不同。模块在其他 Android API 上主动停用；能安装 APK 不等于能启动模块。请先确认：

- 手机已 Root，已安装支持 **libxposed API 101** 的模块框架，可对系统框架启用模块。仅安装 APK 或仅取得 Root 不足以工作。
- 手机 Type-C 端口支持有线视频输出。可直连兼容的显示器、电视、投影仪或 AR 眼镜，也可使用支持视频输出的 Type-C 转 HDMI / DP 转接器。普通充电线不能替代视频线。
- 应用按显示器协商的分辨率和刷新率工作。触控板不需要物理鼠标；也可连接蓝牙或 USB 键鼠。不是多窗口桌面，不提供无线投屏。

## 首次安装

1. 从本仓库 Releases 下载并安装一个 `external-display-helper-1.1.0.apk`。需要时可将文件的 SHA-256 与同页 `SHA256SUMS` 比对。
2. 在模块管理器中启用「外屏助手」，作用域选择系统框架（Android）。无需勾选第三方应用或互联应用。
3. 重启手机，连接外屏，打开「外屏助手」→「更多应用」，选择要在外屏运行的应用。再次选择其他应用即可切换。

## 从双应用旧版升级

合并版沿用旧**外屏适配**的包名 `dev.codex.externaldisplay.input` 和正式签名，安装时替换的是模块。旧**外屏助手**的包名为 `dev.codex.externaldisplay.probe`，不会被覆盖，最近应用记录也不会迁移。

1. 退出旧助手，覆盖安装新版。若暂时出现两个同名桌面图标，可在系统应用详情中按包名或版本区分。
2. 检查模块管理器中 1.1.0 的「外屏助手」已启用、作用域为系统框架，然后重启。旧的模块代码在重启之前可能仍在内存中。
3. 从新版打开一个外屏应用，确认键鼠、触控板、黑屏及拔线恢复正常后，可卸载旧助手 `dev.codex.externaldisplay.probe`。请保留新版 `dev.codex.externaldisplay.input`。不要同时启用其他桌面模式实验模块。

如需停用，在模块管理器关闭「外屏助手」后重启。要退回旧版，先备份需要的设置和原安装包；Android 可能不允许直接覆盖降级，卸载会清除对应应用数据。

## 使用与已知边界

| 功能 | 行为 |
| --- | --- |
| 启动与切换 | 默认显示手机触控板；顶部提供最近使用的 6 个应用及「更多应用」。一次控制一个外屏前台应用。 |
| 触控板与方向 | 单指移动、点按点击、长按拖动、双指滚动。「外屏返回」作用于外屏应用。手机界面可随姿态切换并锁定；不旋转显示器。虚拟光标闲置自动隐藏，使用物理鼠标时可能看到两个光标。 |
| 内屏黑屏 | 手动或无手机操作 1 分钟后，内屏显示黑色并降至最低窗口亮度；单击内屏恢复。这不等于系统锁屏或关闭面板，不改变实体电源键。 |
| 金铲铲之战 | 在助手控制的外屏会话中，按 1.7 参考宽度减 2 像素居中显示，避免取整影响平板布局。例如 1080p 目标为 1834×1080，不修改物理输出模式。原版实测设备保留第三方平板识别配置；不能保证所有版本都显示「下方商店」。 |
| 抖音 | 已适配重复进入「大屏扩展播放」的问题。直播间内部控件错位、内容宽高比不属于本项修复。 |

部分应用可能限制外屏显示、方向或受保护内容。应用接力未单独回归测试。遇到「模块未回应」先检查系统 API、模块启用状态及是否重启；若没有显示器，先确认系统本身能通过当前线材输出视频。
