# 外屏助手 · External Display Helper

<img src="docs/icon.png" width="72" alt="外屏助手图标">

将手机直连显示器，在外屏全屏打开一个 Android 应用，同时把手机当作触控板。日常使用无需电脑、无线 ADB 或投屏服务器。安装后在模块管理器启用「外屏助手」即可使用。

**[下载 APK 与 SHA-256 校验文件](https://github.com/lwm38741/ExternalDisplayHelper/releases)** · [从源码构建](docs/BUILD.md)

## 适配范围

本项目基于**小米 17、HyperOS、Android API 37** 开发。1.1.0 已在该手机连接 AR 眼镜（1920×1080、60Hz）的环境下完成安装及重启加载，用户确认触控板点击、滚动、应用切换和内屏黑屏正常。

其他机型、ROM、系统更新及显示设备请自行测试。即使同为 API 37，厂商系统内部接口也可能不同。模块在其他 Android API 上主动停用；能安装 APK 不等于能启动模块。请先确认：

- 手机已 Root，已安装支持 **libxposed API 101** 的模块框架，可对系统框架启用模块。仅安装 APK 或仅取得 Root 不足以工作。
- 手机 Type-C 端口支持有线视频输出。可直连兼容的显示器、电视、投影仪或 AR 眼镜，也可使用支持视频输出的 Type-C 转 HDMI / DP 转接器。普通充电线不能替代视频线。
- 应用按显示器协商的分辨率和刷新率工作。触控板不需要物理鼠标；也可连接蓝牙或 USB 键鼠。不是多窗口桌面，不提供无线投屏。

## 首次安装

1. 从本仓库 Releases 下载并安装一个 `external-display-helper-1.1.0.apk`。需要时可将文件的 SHA-256 与同页 `SHA256SUMS` 比对。
2. 在模块管理器中启用「外屏助手」，作用域选择系统框架（Android）。无需勾选第三方应用或互联应用。
3. 重启手机，连接外屏，打开「外屏助手」→「更多应用」，选择要在外屏运行的应用。再次选择其他应用即可切换。

## 更新与停用

后续版本可使用同签名 APK 覆盖安装。更新后请检查模块启用状态，并重启手机加载新代码。请避免同时启用功能冲突的桌面模式模块。

如需停用，在模块管理器关闭「外屏助手」后重启。卸载会清除应用设置。

## 使用与已知边界

| 功能 | 行为 |
| --- | --- |
| 启动与切换 | 默认显示手机触控板；顶部提供最近使用的 6 个应用及「更多应用」。一次控制一个外屏前台应用。 |
| 触控板与方向 | 单指移动、点按点击、长按拖动、双指滚动。「外屏返回」作用于外屏应用。手机界面可随姿态切换并锁定；不旋转显示器。虚拟光标闲置自动隐藏，使用物理鼠标时可能看到两个光标。 |
| 内屏黑屏 | 手动或无手机操作 1 分钟后，内屏显示黑色并降至最低窗口亮度；单击内屏恢复。这不等于系统锁屏或关闭面板，不改变实体电源键。 |
| 金铲铲之战 | 在助手控制的外屏会话中，按 1.7 参考宽度减 2 像素居中显示，避免取整影响平板布局。例如 1080p 目标为 1834×1080，不修改物理输出模式。实测设备保留第三方平板识别配置；不能保证所有版本都显示「下方商店」。 |
| 抖音 | 已适配重复进入「大屏扩展播放」的问题。直播间内部控件错位、内容宽高比不属于本项修复。 |

部分应用可能限制外屏显示、方向或受保护内容。应用接力未单独回归测试。遇到「模块未回应」先检查系统 API、模块启用状态及是否重启；若没有显示器，先确认系统本身能通过当前线材输出视频。
